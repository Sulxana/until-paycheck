# ხელფასამდე — შენი ფულის ამინდის პროგნოზი

**Until Payday** — a working web prototype for the UNI4VERSE – FINEDU 2026 final (Tbilisi, 2 November 2026).

ხელფასამდე შენი ყველა ბანკის ისტორიიდან ითვლის, რამდენი დღის ფული დაგრჩა ხელფასამდე; ყოველი შესყიდვის, განვადების ან სესხის წინ შენივე რიცხვებით გაჩვენებს, რა დაგიჯდება სინამდვილეში; და დღეში ორ წუთში გასწავლის, რატომ.

> მუშა პროტოტიპი სინთეტიკურ მონაცემებზე. ბანკთან კავშირი ჯერ არ არის. ინფორმაციაა, არა რჩევა.

## რა არის შიგნით

| ეკრანი | რას აკეთებს |
|---|---|
| **გზა** | მთის გზა ხელფასამდე: ერთი უჯრა ერთი დღეა, ამინდი გზის თავზე — თვითონ პროგნოზი. შესყიდვის შემოწმება ერთი შეხებით. „დროის მანქანა" ხელფასის დღემდე და ჩასვლის ცერემონია. |
| **ანალიზი** | ბალანსის დიაპაზონი ხელფასამდე (p10/p50/p90), გადასახადები მტკიცებულებით, 12 თვის პროგნოზი „რა მოხდება, თუ…" გადამრთველებით, ხარჯები კატეგორიებით. |
| **ჯიხო** | ჩატი: შესყიდვა, განვადება, სესხი, „დღეს რამდენი შემიძლია", ფინანსური ცნებები. ყველა რიცხვს ძრავა ითვლის; ჯიხო მხოლოდ ხსნის. ოფლაინ მუშაობს. |
| **სოფელი** | კოშკი, ქვევრი, ამინდის სადგური, სკოლა, ხიდი — იზრდება მხოლოდ დადასტურებული კარგი ქმედებით. საქართველოს რუკა 12 ადგილით. |
| **დღე** | დილის 2-წუთიანი გაკვეთილი (გამეორება, ახალი, შენი რიცხვებით), საღამოს 40-წამიანი დახურვა, „აჯობე პროგნოზს", კვესტები. |

სამი სინთეტიკური პერსონა: **ნინო** (ხელფასიანი, 3 ბანკი), **ლუკა** (სტუდენტი), **თამარი** (ოვერდრაფტი, გაჭირვების რეჟიმი).

## ძრავა

`src/engine/` — `engine_v0.py`-ის ზუსტი TypeScript ასლი: განმეორებადი გადასახადები, დღიური ხარჯი კვირის დღეების მიხედვით, 1 000-ტრაექტორიიანი bootstrap, ანუიტეტი, მრავალთვიანი სიმულაცია ბალანსის გადატანით. Python-ის `random` გენერატორი (MT19937) ბიტ-ბიტ არის გადატანილი, ამიტომ **იგივე seed (20261102) იძლევა ზუსტად იგივე რიცხვებს**, რაც კონცეფციის დოკუმენტშია.

```bash
npm run verify   # ადარებს ძრავას engine_v0_report.json-ს (reference/engine_v0.py → reference/engine_v0_report.json)
```

## თამაშის 10 წითელი ხაზი

ხარჯვა, სესხი და აპის გახსნა არასდროს აჯილდოებს · შემთხვევითობა ფულზე არ ებმება, ყიდვით არაფერი იხსნება · ჯიხო ქმედებას ასახავს, არა ბალანსს; არ კვდება · „დაველოდები" და „ვყიდულობ" თანაბარ პროგრესს იძლევა · ერთი აღდგენადი სერია · შეტყობინებები მხოლოდ თანხმობით · გაჭირვების რეჟიმი · თამაშის გამორთვა სრულ ინსტრუმენტს ტოვებს · ბანკის ფლოუში თამაში არ არის · სოციალურში მხოლოდ გაუმჯობესება.

## გაშვება

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/
npx vite build --mode single   # dist-single/index.html — ერთი ფაილი, ინტერნეტის გარეშე
```

Stack: React 18, TypeScript, Vite, framer-motion, zustand. No backend: everything runs in the browser.
